# メジャー大会戦績

オセロ名人戦・全日本オセロ選手権・オセロ王座戦（2004年〜）の順位と全対局を見やすくまとめたサイト。
データは [日本オセロ連盟レーティング](https://www.othello.gr.jp/rate/rate_tournaments) の大会ページから作っています。

## 公開に必要なファイル

`index.html`・`style.css`・`app.js`・`results.json` の4つだけです（`tools/` は無くても動きます）。

## 新しい大会を追加するとき

1. 連盟レーティングの大会一覧で、追加したい大会の番号（URL の最後の数字）を調べる
2. `tools/tournaments.tsv` に1行追加する（タブ区切り：番号・日付・棋戦・大会名）
   ```
   5100	2026-11-08	全日本	第52回全日本オセロ選手権
   ```
   棋戦は `名人戦`・`全日本`・`王座戦` のどれか
3. 次を実行すると `results.json` が作り直される
   ```
   python3 tools/build.py
   ```
4. `results.json` をアップロードし直す

## 補足

- 順位は連盟レーティングの大会ページの掲載順です
- 石数は、元ページに本物の石数が載っている大会だけ表示します（勝ち64・負け0だけの大会は「石数の記録なし」）
- 地区予選・ブロック大会・地区名人戦は含めていません
